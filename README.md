# 영어 공부방

`매일 영어`(OPIc IH 실전 표현 1000)와 `토익 보카`(해커스 토익 기출 보카 30일)를
**한 앱**으로 묶은 학습 페이지입니다. 설치는 한 번, 홈에서 두 앱을 오갑니다.

앱 주소: <https://gywn000929-bot.github.io/Hackers-Toeic/>

```
index.html                      홈 — 오늘 학습 현황과 두 앱 입구
├── opic_ih_daily_english.html  매일 영어 · OPIc IH 실전 표현 1000   → README_opic.md
└── hackers_toeic_vocab_30.html 토익 보카 · 해커스 기출 보카 30일    → README_toeic.md
```

- 홈에서는 **연속 학습일 · 오늘 복습 · 오늘 영작 · 완료 카드**를 두 앱 합산으로 보여줍니다.
- 각 앱의 왼쪽 위(매일 영어는 `IH` 마크, 토익 보카는 `←`)를 누르면 홈으로 돌아옵니다.
- 외부 CDN·스크립트를 전혀 쓰지 않아 **인터넷 없이** 열립니다.
  글꼴(Pretendard)도 저장소에 함께 담아 두어 어느 기기에서나 같은 모습입니다.
- **테마 4종 + 자동** — 라이트 · 세피아 · 그레이 · 다크. 세 화면이 함께 바뀝니다.
- 학습 기록은 기기의 브라우저에 저장되며, 두 앱이 각자 보관합니다.

## 앱으로 설치하기

한 번 설치하면 두 앱이 함께 들어옵니다. 설치본은 주소창 없이 자기 창으로 뜨고,
한 번 열어둔 뒤에는 비행기 모드에서도 열립니다.

### 윈도우 (엣지 · 크롬)

1. 위 앱 주소를 엣지나 크롬으로 엽니다.
2. 주소창 오른쪽 끝의 **설치 아이콘**(⊕ 또는 모니터 모양)을 누릅니다.
   안 보이면 `⋯` 메뉴 → 엣지는 **앱 → 이 사이트를 앱으로 설치**,
   크롬은 **저장 및 공유 → 페이지를 앱으로 설치**. 홈 화면의 **설치** 버튼도 같습니다.
3. 설치 창에서 **바탕 화면에 바로 가기 만들기**를 체크하면 바탕화면에 아이콘이 생깁니다.

작업 표시줄 아이콘을 오른쪽 클릭하면 **매일 영어 / 토익 보카**로 바로 가는
바로 가기 메뉴가 나옵니다.

### 아이폰 · 아이패드 (사파리)

공유 버튼 → **홈 화면에 추가**. (사파리에는 설치 버튼이 없어 이 방법만 됩니다.)

### 안드로이드 (크롬)

메뉴 → **앱 설치**, 또는 홈 화면의 **설치** 버튼.

> 예전에 `매일 영어`와 `토익 보카`를 따로 설치해 두었다면, 그 둘을 지우고
> 위 주소에서 한 번만 다시 설치하세요. 학습 기록은 같은 브라우저 저장소를 쓰므로
> 그대로 남습니다.

## 발음 듣기

기기에 내장된 음성(Web Speech API)으로 읽어 줍니다. **인터넷에 연결된 음성보다
기기에 설치된 음성을 먼저 고릅니다** — 엣지의 `Online (Natural)` 음성은 네트워크가
막히면 오류도 없이 조용히 끝나는 일이 있어서입니다.

아이폰과 설치한 앱 창에서는 첫 재생이 조용히 씹히는 일이 있어, 화면을 처음 누를 때
무음으로 한 번 음성 엔진을 깨워 둡니다.

소리가 나지 않으면 토익 보카의 DAY 서랍에서:

- **발음 음성** — 다른 음성을 골라 바로 들어볼 수 있습니다.
  고른 음성은 `english-room-voice`에 저장되어 두 앱이 함께 씁니다.
- **소리가 안 나나요?** — 브라우저 지원 여부, 음성 개수, 고른 음성, 실행 방식(앱/탭),
  마지막 재생 결과를 보여줍니다. 아래 경우를 특히 확인해 주세요.
  - 설치한 앱은 **완전히 닫았다 다시 열어야** 새 버전이 적용됩니다
    (새 버전이 자리를 잡으면 앱이 한 번 자동으로 새로고침합니다).
  - 윈도우 **볼륨 믹서**에는 설치한 앱이 브라우저와 따로 잡힙니다 — 음소거인지 확인.
  - 아이폰은 **측면 무음 스위치**가 켜져 있으면 소리가 나지 않습니다. 벨소리 볼륨도 함께 확인.
  - 아이폰에 영어 음성이 없으면 **설정 → 손쉬운 사용 → 콘텐츠 말하기 → 음성**에서 받아 주세요.

### 아이폰에서 특히 신경 쓴 것

사파리는 `speechSynthesis`가 조용히 실패하는 조건이 몇 가지 있어 이렇게 피해 갑니다.

- `cancel()` 직후 `speak()` 하면 무음이 되는 일이 있어, **실제로 말하는 중일 때만** 멈춥니다.
- `utterance.voice`를 직접 지정하면 무음이 되는 경우가 있어, 사용자가 서랍에서
  직접 고르지 않았다면 **기기 기본 음성에 맡깁니다**.
- 시작이 느릴 수 있어 무음 판정을 **2.5초**로 잡고, 그 사이 재생이 시작되면 건드리지 않습니다.
- 첫 조작 때 공백 한 칸을 무음으로 읽어 음성 엔진을 깨웁니다.

## 고치고 다시 만들기

```bash
node build.js     # src/template.html + src/data/*.js → opic_ih_daily_english.html
```

화면을 크게 바꿨다면 `screenshots/`의 미리보기도 같은 크기로 다시 찍고,
`sw.js`의 `CACHE` 버전을 올리세요. 그래야 기존 설치본이 새 파일을 받아갑니다.
