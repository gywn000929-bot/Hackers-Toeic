# 영어 공부방

`매일 영어`(OPIc IH 실전 표현 1000)와 `토익 보카`(해커스 토익 기출 보카 30일)를
**한 앱**으로 묶은 학습 페이지입니다. 설치는 한 번, 홈에서 두 앱을 오갑니다.

앱 주소: <https://gywn000929-bot.github.io/Hackers-Toeic/>

```
index.html                      홈 — 오늘 학습 현황과 두 앱 입구
├── opic_ih_daily_english.html  매일 영어 · OPIc IH 실전 표현 1000   → README_opic.md
└── hackers_toeic_vocab_30.html 토익 보카 · 해커스 기출 보카 30일    → README_toeic.md
```

- 홈에서는 **연속 학습일 · 오늘 복습 · 오늘 영작 · 완료 카드**를 두 앱 합산으로 보여줍니다.
- 각 앱의 왼쪽 위(매일 영어는 `IH` 마크, 토익 보카는 `←`)를 누르면 홈으로 돌아옵니다.
- 외부 CDN·폰트·스크립트를 전혀 쓰지 않아 **인터넷 없이** 열립니다.
- 학습 기록은 기기의 브라우저에 저장되며, 두 앱이 각자 보관합니다.

## 앱으로 설치하기

한 번 설치하면 두 앱이 함께 들어옵니다. 설치본은 주소창 없이 자기 창으로 뜨고,
한 번 열어둔 뒤에는 비행기 모드에서도 열립니다.

### 윈도우 (엣지 · 크롬)

1. 위 앱 주소를 엣지나 크롬으로 엽니다.
2. 주소창 오른쪽 끝의 **설치 아이콘**(⊕ 또는 모니터 모양)을 누릅니다.
   안 보이면 `⋯` 메뉴 → 엣지는 **앱 → 이 사이트를 앱으로 설치**,
   크롬은 **저장 및 공유 → 페이지를 앱으로 설치**. 홈 화면의 **설치** 버튼도 같습니다.
3. 설치 창에서 **바탕 화면에 바로 가기 만들기**를 체크하면 바탕화면에 아이콘이 생깁니다.

작업 표시줄 아이콘을 오른쪽 클릭하면 **매일 영어 / 토익 보카**로 바로 가는
바로 가기 메뉴가 나옵니다.

### 아이폰 · 아이패드 (사파리)

공유 버튼 → **홈 화면에 추가**. (사파리에는 설치 버튼이 없어 이 방법만 됩니다.)

### 안드로이드 (크롬)

메뉴 → **앱 설치**, 또는 홈 화면의 **설치** 버튼.

> 예전에 `매일 영어`와 `토익 보카`를 따로 설치해 두었다면, 그 둘을 지우고
> 위 주소에서 한 번만 다시 설치하세요. 학습 기록은 같은 브라우저 저장소를 쓰므로
> 그대로 남습니다.

## 구조

| 파일 | 설명 |
|---|---|
| `index.html` | 홈. 두 앱 입구와 오늘 학습 현황 |
| `opic_ih_daily_english.html` | 매일 영어 (빌드 결과물 — `src/`에서 생성) |
| `hackers_toeic_vocab_30.html` | 토익 보카 (단일 파일) |
| `manifest.webmanifest` | 앱 정보. `id`/`start_url`은 홈(`./`) |
| `sw.js` | 세 화면과 아이콘을 캐시하는 서비스 워커 |
| `icons-app/` | 앱 아이콘. `icons/`·`icons-toeic/`는 바로 가기 메뉴용 |
| `screenshots/` | 설치 대화상자 미리보기 (`home-wide` 1280×800, `home-narrow` 430×932) |

## 고치고 다시 만들기

```bash
node build.js     # src/template.html + src/data/*.js → opic_ih_daily_english.html
```

화면을 크게 바꿨다면 `screenshots/`의 미리보기도 같은 크기로 다시 찍고,
`sw.js`의 `CACHE` 버전을 올리세요. 그래야 기존 설치본이 새 파일을 받아갑니다.
