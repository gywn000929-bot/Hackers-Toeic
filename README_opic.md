# 매일 영어 · OPIc IH 실전 표현 1000

일상에서 실제로 쓰는 성인 OPIc **IH 수준**의 단어 · 숙어 · 문장 **1000개**를
주제별 탭으로 담은 인터랙티브 학습 페이지입니다.

## 열기

`opic_ih_daily_english.html` 파일 하나만 있으면 됩니다.
외부 CDN·폰트·스크립트를 전혀 쓰지 않으므로 **비행기 모드에서도** 동작합니다.
휴대폰으로 옮겨 열거나, 아래처럼 앱으로 설치해 쓰세요.

앱 주소: <https://gywn000929-bot.github.io/Hackers-Toeic/opic_ih_daily_english.html>

## 앱으로 설치하기

휴대폰과 **윈도우·맥 데스크톱 모두** 설치됩니다. 설치하면 브라우저 주소창 없이
자기 창으로 뜨고, 서비스 워커가 내용을 받아두어 **인터넷이 끊겨도** 열립니다.
학습 기록은 기기에 저장되므로 기기마다 따로 쌓입니다.

### 윈도우 (엣지 · 크롬)

1. 위 앱 주소를 엣지나 크롬으로 엽니다.
2. 주소창 오른쪽 끝의 **설치 아이콘**(⊕ 또는 모니터 모양)을 누릅니다.
   안 보이면 `⋯` 메뉴 → 엣지는 **앱 → 이 사이트를 앱으로 설치**,
   크롬은 **저장 및 공유 → 페이지를 앱으로 설치**.
   앱 안의 **설정 & 학습 현황 → 앱으로 설치** 버튼을 눌러도 됩니다.
3. 설치 창에서 **바탕 화면에 바로 가기 만들기**를 체크하면 바탕화면에 아이콘이 생깁니다.
   시작 메뉴와 작업 표시줄에도 고정할 수 있습니다.

설치한 앱을 지우려면 **설정 → 앱**에서 `매일 영어`를 제거하거나,
앱 창의 `⋯` → **제거**를 누릅니다.

### 아이폰 · 아이패드 (사파리)

공유 버튼 → **홈 화면에 추가**. (사파리에는 설치 버튼이 없어 이 방법만 됩니다.)

### 안드로이드 (크롬)

메뉴 → **앱 설치** 또는 화면 아래에 뜨는 설치 안내.

롤플레이 · 과거경험 · 의견·연결어

## 기능

- **주제 탭** 가로 스크롤 + **단어 / 표현 / 문장 / ★ / 🧠 복습** 세그먼트
- **가리기 모드** — 뜻 가리기 ↔ 영어 가리기 ↔ 끄기 (카드를 탭하면 잠깐 공개)
- **발음 듣기** — 기기 내장 TTS로 표제어와 예문 재생
- **즐겨찾기 ★** 와 **학습 완료 ✓** — 주제별 진도 바 표시
- **🧠 복습 (안키식 간격 반복)** — SM-2 알고리즘. 카드마다 **다시 / 어려움 / 보통 / 쉬움**을
  고르면 맞힌 카드는 1일 → 3일 → 8일 → 3주로 간격이 벌어지고, 틀린 카드는 몇 분 뒤 다시 나옵니다.
  하루 새 카드·복습 상한, 출제 방향(영→한 / 한→영 / 섞기), 복습 범위(전체 / 이 주제 / ★) 설정 가능.
  카드 상태 분포, 앞으로 7일 복습 예정, 연속 학습일을 대시보드에서 확인합니다.
  하루 경계는 새벽 4시라 밤늦게 공부해도 같은 날로 셉니다.
- **퀴즈** — 12문항 4지선다, 영↔한 양방향. 오답은 자동으로 ★에 저장
- **플래시카드** — 좌우 스와이프, 탭하면 뒤집기
- **전체 검색** — 영어 · 한글 · 예문까지 한 번에
- **글자 크기 4단계**, **라이트/다크 테마**, **완료 항목 숨기기**
- 모든 기록은 기기에 저장되어 다시 열어도 유지됩니다
- 데스크톱 창에서는 마우스 호버 표시와 키보드가 동작합니다 — **Esc** 시트 닫기,
  플래시카드에서 **← →** 이동 · **스페이스** 뒤집기

## 수정하고 다시 만들기

내용은 `src/data/t01.js` ~ `t20.js`, 화면은 `src/template.html`에 있습니다.

```bash
node build.js     # → opic_ih_daily_english.html 재생성 + 개수 집계 출력
```

화면을 크게 바꿨다면 설치 창에 뜨는 미리보기(`screenshots/wide.png` 1280×800,
`screenshots/narrow.png` 430×932)도 같은 크기로 다시 찍어 두세요.
`sw.js`의 `CACHE` 버전을 올리면 기존 설치본이 새 파일을 받아갑니다.
