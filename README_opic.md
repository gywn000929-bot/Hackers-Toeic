# 매일 영어 · OPIc IH 실전 표현 1000 (모바일 전용)

일상에서 실제로 쓰는 성인 OPIc **IH 수준**의 단어 · 숙어 · 문장 **1000개**를
주제별 탭으로 담은 인터랙티브 학습 페이지입니다.

## 열기

`opic_ih_daily_english.html` 파일 하나만 있으면 됩니다.
외부 CDN·폰트·스크립트를 전혀 쓰지 않으므로 **비행기 모드에서도** 동작합니다.
휴대폰으로 옮겨 열거나, 브라우저에서 열고 홈 화면에 추가해 앱처럼 쓰세요.

## 구성 (20주제 × 50개 = 1000개)

| 구분 | 개수 | 내용 |
|---|---|---|
| 단어 | 400 | 발음기호 · 품사 · 뜻 · 예문 · 출제 포인트 |
| 표현·숙어 | 300 | 원어민 구동사와 관용구 · 예문 |
| 문장 | 300 | 답변에 그대로 쓰는 문장 + 활용 태그 · 팁 |

주제: 자기소개/성격 · 직업 · 집/동네 · 가족/친구 · 취미 · 영화 · 음악 · 운동 ·
여행 · 음식 · 카페 · 쇼핑 · 교통 · 날씨 · 기술 · 공부 · 은행·병원 ·
롤플레이 · 과거경험 · 의견·연결어

## 기능

- **주제 탭** 가로 스크롤 + **단어 / 표현·숙어 / 문장 / ★** 세그먼트
- **가리기 모드** — 뜻 가리기 ↔ 영어 가리기 ↔ 끄기 (카드를 탭하면 잠깐 공개)
- **발음 듣기** — 기기 내장 TTS로 표제어와 예문 재생
- **즐겨찾기 ★** 와 **학습 완료 ✓** — 주제별 진도 바 표시
- **퀴즈** — 12문항 4지선다, 영↔한 양방향. 오답은 자동으로 ★에 저장
- **플래시카드** — 좌우 스와이프, 탭하면 뒤집기
- **전체 검색** — 영어 · 한글 · 예문까지 한 번에
- **글자 크기 4단계**, **라이트/다크 테마**, **완료 항목 숨기기**
- 모든 기록은 기기에 저장되어 다시 열어도 유지됩니다

## 수정하고 다시 만들기

내용은 `src/data/t01.js` ~ `t20.js`, 화면은 `src/template.html`에 있습니다.

```bash
node build.js     # → opic_ih_daily_english.html 재생성 + 개수 집계 출력
```
