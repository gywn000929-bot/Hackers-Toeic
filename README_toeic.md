# 해커스 토익 기출 보카 · 30일 완성

토익 기출 단어를 DAY 1~30으로 나눠 담은 인터랙티브 전자책입니다.
단어마다 발음기호 · 품사 · 뜻 · 예문 · 출제 팁 · 파생어가 붙어 있고,
DAY별 퀴즈와 전체 검색이 들어 있습니다.

파일 하나(`hackers_toeic_vocab_30.html`)로 동작합니다.

앱 주소: <https://gywn000929-bot.github.io/Hackers-Toeic/hackers_toeic_vocab_30.html>

## 기능

- **학습** — DAY별 단어 카드. 발음기호 · 품사 · 뜻 · 예문 · 출제 팁 · 파생어, 단어별 ○ 체크로 진도 관리
- **퀴즈** — 뜻 맞히기 · 단어 맞히기 · 빈칸 채우기 · 철자 맞추기 · 속도전
- **✍️ 영작** — 예문의 한글 해석만 보고 영어로 직접 써 봅니다.
  책 속 모범 예문과 단어 단위로 맞춰 100점 만점 점수를 매기고,
  맞은 단어(초록) · 어형만 다른 단어(주황 점선) · 군더더기(취소선) · 빠진 단어를 표시합니다.
  출제 범위는 **오늘 체크한 단어 / DAY 01~30 / 전체**, 한 세트는 10문장입니다.
  ○ 로 체크하거나 퀴즈에서 맞힌 단어가 '오늘 체크한 단어'로 모입니다.
- **전체 검색** — 영어 · 한글 · 예문까지 한 번에

채점은 인터넷 없이 앱 안에서 돌아갑니다. AI가 문장을 새로 판단하는 것이 아니라
책에 실린 모범 예문과 얼마나 겹치는지를 보는 방식이라, 뜻이 같아도 표현이 다르면
점수가 낮게 나올 수 있습니다. 점수보다 '빠진 단어'를 참고하는 쪽이 도움이 됩니다.

## 앱으로 설치하기

`매일 영어`(OPIc)와 같은 방식으로 **윈도우·맥 데스크톱과 휴대폰 모두** 설치됩니다.
설치하면 주소창 없이 자기 창으로 뜨고, 한 번 열어둔 뒤에는 인터넷이 끊겨도 열립니다.
학습 체크 기록은 기기에 저장되므로 기기마다 따로 쌓입니다.

### 윈도우 (엣지 · 크롬)

1. 위 앱 주소를 엣지나 크롬으로 엽니다.
2. 헤더의 **⬇️ 설치** 버튼을 누릅니다. (주소창 오른쪽 끝의 설치 아이콘,
   또는 `⋯` 메뉴 → 엣지 **앱 → 이 사이트를 앱으로 설치** / 크롬 **저장 및 공유 → 페이지를 앱으로 설치**도 같습니다.)
3. 설치 창에서 **바탕 화면에 바로 가기 만들기**를 체크하면 바탕화면에 아이콘이 생깁니다.

### 아이폰 · 아이패드 (사파리)

공유 버튼 → **홈 화면에 추가**. (사파리에는 설치 버튼이 없어 이 방법만 됩니다.)

### 안드로이드 (크롬)

메뉴 → **앱 설치**, 또는 헤더의 **⬇️ 설치** 버튼.

## 참고

- 오프라인 캐시는 저장소 공통 `sw.js`가 `매일 영어`와 함께 담당합니다.
  내용을 고쳐 배포할 때는 `sw.js`의 `CACHE` 버전을 올려야 설치본이 새 파일을 받아갑니다.
- 글꼴은 `매일 영어`와 같은 방식으로 **기기에 있는 것만** 씁니다 (CDN 요청 0건).
  한글은 Pretendard → Apple SD Gothic Neo → 맑은 고딕 순으로, 영어 단어와 예문은
  세리프(Iowan Old Style / Palatino / Georgia)로 조판되어 처음부터 오프라인이어도
  똑같이 보입니다.
- 색·글꼴·여백은 `매일 영어`의 값을 그대로 씁니다. 잉크 네이비 `#16233d`,
  포인트 블루 `#2f5fd0`, 옅은 헤어라인 `#e4e9f2`, 따뜻한 모래빛 팁 배경.
- 720px 이하 화면에서는 DAY 목록이 위쪽 가로 스크롤 칩으로 바뀌고,
  검색창이 한 줄을 차지하며 DAY 머리글이 두 줄로 접힙니다.
- 설치 창에 뜨는 미리보기는 `screenshots/toeic-wide.png`(1280×800),
  `screenshots/toeic-narrow.png`(430×932)입니다. 화면을 크게 바꾸면 같이 다시 찍어 주세요.
